# Android-VM-Build

Android-VM-Build is an Ansible project customizes your VM for Android Penetration Tests & CTF challenges. It can mainly be used in Ubuntu OS(Parrot too). 

## Prerequisite:
Firstly, Run `ansible_installation.sh` to install ansible & other components for hassle free Android VM building.
